# e-Defter Denetim Merkezi — Windows App Logo Set

Bu paket seçilen büyüteç + e + defter logosu için hazırlanmıştır.

## İçerik

- `edefter-denetim-merkezi.ico`  
  Windows uygulama ikonu. EXE, installer, masaüstü kısayolu, taskbar, Start Menu ve Denetim Masası için kullanılabilir.

- `edefter-denetim-merkezi-logo-master-1024-transparent.png`  
  Şeffaf arka planlı ana logo. Uygulama içi header, splash, about ekranı ve yüksek çözünürlüklü kullanım için.

- `edefter-denetim-merkezi-logo-master-1024-tile.png`  
  Açık arka planlı kare tile versiyonu. Windows Start Menu, installer görselleri veya dokümantasyon için.

- `png/`  
  16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256, 512x512 PNG ikonlar.

- `windows/`  
  Denetim Masası, Start Menu ve installer için ayrı dışa aktarımlar.

## Kullanım Notu

Logo anlamı:
- Açık defter: e-Defter arşivi
- Büyüteç: denetim / kontrol
- `e`: e-Defter kimliği

## Ürün Uyarısı

Bu paket resmi GİB logosu veya kamu kurumu amblemi içermez. Uygulama, GİB onayı veren bir sistem gibi sunulmamalıdır.

Zorunlu ifade:
"Bu uygulama resmi GİB onayı vermez. Mevcut e-Defter arşivleri üzerinde ön denetim, dosya bütünlüğü ve arşiv kontrolü yapar."
